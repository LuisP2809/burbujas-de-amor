# Burbujas de Amor 💗

Experiencia web interactiva en la que cada burbuja revela un mensaje diferente.

## Funciones incluidas

- Diseño moderno tipo glassmorphism.
- Burbujas animadas y adaptables a celular, tablet y computadora.
- 18 mensajes sin repeticiones hasta completar la colección.
- Contador y barra de progreso.
- Partículas y celebración final.
- Música ambiental y efectos creados con Web Audio API, sin archivos externos.
- Control de sonido, reinicio e instalación como aplicación.
- Accesibilidad con botones reales, etiquetas y movimiento reducido.
- PWA con funcionamiento offline.
- Personalización opcional mediante `?para=Nombre`.

## Personalizar el nombre

Puedes abrir el sitio con un nombre en la dirección:

```text
https://luisp2809.github.io/burbujas-de-amor/?para=Nombre
```

## Publicar con GitHub Pages

1. Abre **Settings → Pages** en este repositorio.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Escoge la rama `main` y la carpeta `/ (root)`.
4. Guarda los cambios.

El sitio quedará disponible en:

```text
https://luisp2809.github.io/burbujas-de-amor/
```

## Archivos

- `index.html`: interfaz, estilos y funcionamiento de la experiencia.
- `manifest.webmanifest`: configuración para instalarla como PWA.
- `sw.js`: caché y funcionamiento offline.
- `icon.svg`: icono adaptable de la aplicación.
